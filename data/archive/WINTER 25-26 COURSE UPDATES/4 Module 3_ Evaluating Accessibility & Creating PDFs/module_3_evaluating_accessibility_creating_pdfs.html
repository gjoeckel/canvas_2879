Objective

Review processes for utilizing built-in accessibility checkers and an evaluation checklist, installing Adobe PDF Maker, and exporting PDF documents.

Components

This module has three Sections:

  • Section 1: Evaluating Accessibility
  • Section 2: Practicing Evaluation & Repair
  • Section 3: Creating PDFs

Each Section has a Quiz with multiple-choice questions. You should answer all Section Quiz questions correctly before moving on to the next Section.

After you have completed all of the Section Quizzes, take the Exam.

Exam

Exam 3 has ten questions that have been randomly selected from each of the Module 3 Section Quizzes.
