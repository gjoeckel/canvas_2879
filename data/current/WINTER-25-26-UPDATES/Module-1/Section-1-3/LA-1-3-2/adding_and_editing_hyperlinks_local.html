Adding and Editing Hyperlinks

Hyperlinks are a powerful tool for expanding the formats and methods for presenting information in an electronic document. Links to resources such as articles, videos, podcasts, and social media allow authors to leverage some of the awesome potential of web-based documents.

Objectives

  • Identify the process for adding and editing Hyperlinks.

Introduction

The process for adding and editing hyperlinks is the SAME in the Windows and Mac versions of Word and PowerPoint. There are some differences between the look and layout of the Windows and Mac user interfaces—

—but the labels for the fields and buttons used to add and edit links are the same.

Adding a Hyperlink with Existing Text

This link is not understandable when heard or seen without the context of the preceding text. To fix this issue I'll create a Hyperlink from existing document text. I'll copy this example and switch to Word on Windows to demonstrate how to do this.

First I'll paste in my example. Then I’ll cut the video's URL to remove the current Hyperlink, and use the "this video" text for a new link.

To create a Hyperlink with existing document text, I'll:

  1. Highlight and right-click the document text;

  2. Select “Link” from the menu;

  3. Type (or paste) the URL in the "Address" field; and,

  4. Click "OK."

You can also use the keyboard shortcut Control + K on Windows (Command + K on Mac) to add a Hyperlink.

Editing Hyperlinks

Now I have some new linked text. But I also have a problem. The linked text—“this video”—is not very specific or descriptive. It does not adequately convey the function of the link. I'll address these issues by changing this text.

To edit linked text I'll:

  1. Right-click the Hyperlink.

  2. Select "Edit Hyperlink" from the menu.

  3. Change the text in the "Text to Display" field.

  4. Click "OK."

Control + K on Windows (Command + K on Mac) will also open the Edit Hyperlink dialog.

Hyperlinked Images
