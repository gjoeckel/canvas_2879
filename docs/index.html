Canvas Course DOCX Editor

Each page in the Canvas course has been converted into a docx file. All docx files are uploaded to Box. Each page has four links:

  • view docx: opens the docx file in the Box viewer.
  • edit docx: opens the docx file in the Box Microsoft Word Online editor.
  • view canvas: opens a local copy of the Canvas page content in a new tab.
  • edit canvas: opens the Canvas page editor in a new tab.
Note: You will need to authenticate to Canvas and Box to use the links.
