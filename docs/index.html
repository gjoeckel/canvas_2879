Canvas Course Page Text Editor

For each page in the Canvas course:

  1. A DOCX file has been created.
  2. The DOCX file has been uploaded to Box.
  3. An Asana task has been created.

Each page has status indicators and links:

  • Asana: task update ? status, and links to open and refresh the task
  • Box: task update status, links to view and edit DOCX, and task review status
  • Canvas: task update status, links to view and edit Canvas page, and task review status
Note: You will need to authenticate to Canvas and Box to use the links.
