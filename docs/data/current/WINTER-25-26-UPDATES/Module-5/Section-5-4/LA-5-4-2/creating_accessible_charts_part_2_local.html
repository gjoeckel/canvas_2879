In the previous video, I covered the first two keys to accessible charts:

  1. Provide the chart data in text format.
  2. Optimize the chart's default elements.

In this video, I will cover the next two:

  1. Add data labels if needed.
  2. Follow accessibility principles for non-text chart elements.

Objectives

  • State two recommendations for labeling a chart's data elements.
  • Describe the process for adding an Alt Text to a Chart Area.

Add Data Labels if Needed

When a user does not have access to a chart's data in text format, adding text labels for some of a chart's elements may be required to optimize accessibility. When a chart's data is not presented on the same sheet as the chart, providing text labels for some of a chart's elements should be strongly considered.

Another major factor to take into account is the type of chart being used. Ultimately—

You must decide when, where and how to label a chart's data elements.

Two recommendations for data labels

When you do add data labels, we suggest that you follow two recommendations:

  1. Select the best position for labels according to the context.
  2. Replicate any number formatting used in the data text.

For charts that use shapes, labels can be positioned inside a shape,
and aligned with the shape in various ways depending on the chart's configuration.

To add data labels to a chart:

    1. Select the chart, and click the "Design" tab under "Chart Tools" on the Ribbon.

    2. Click the "Add Chart Element" tool.

    3. Navigate to "Data Labels", and select a label position (I'll select "Center" for this example).

Outside data shapes

Labels can also be placed outside a shape by navigating to the "Add Chart Element" tool and selecting "Data Callout":

In this example, by default each data callout is positioned directly "on top of" its corresponding segment of the data bar:

Using the mouse to drag and drop, I'll move each label toward the top of the chart, so that it is positioned "above" its segment of the data bar:

As I mentioned previously, there may be insufficient contrast between the default color of text in a data label, and the default colors of shapes. In this example, the default text color has insufficient contrast with both the orange and yellow background colors. I'll darken the color of the text to address this issue, and increase the font size from 9 points to 10.

Formatting labels

The data for this chart is in dollars. I'll select a data cell and make sure the Hᴏᴍᴇ tab on the Ribbon is showing. I can see that the format "Currency" in the "Numbers" section has been applied:

Returning to my chart, I'll double-click the horizontal axis to open the "Format Axis" side panel. On the "Axis Options" tab, I'll expand the "Numbers" section, and I see that the "Currency" format was automatically applied when the chart was created:

However, when I click on a data label on one of the chart's bars, open the "Format Data Labels" side panel, and expand the "Numbers" section, I see that these labels are formatted as "General":

To provide the most equivalent information, I want to ensure that these labels have the same descriptive number formatting that was automatically applied to the horizontal axis.

To apply a "Number" category to a label:

    1. Open the "Format Data Labels" side panel.

    2. Select a category from the drop-down menu in the "Number" section (I'll select "Currency" for this example).

    3. Set the "Decimal places" value appropriately for the context (in this example data, the data are rounded off to closest hundred million, so I'll change this value from "2" to "1").

Follow Accessibility Principles for Non-text Chart Elements

Accessibility principles for non-text chart elements can be organized into two categories: Alt Text and Contrast.

Alt Text for non-text chart elements

Add an Alt Text value to the Chart Area following the process demonstrated in the Images: Part 3 video. We recommend providing a high-level description that includes the chart's type. For this chart, I'll use: "Stacked bar chart of spending on dogs, cats, and other pets in the U.S. from 2011 - 2017":



Please remember that—

When a chart's data is not presented in an accessible text format, a chart summary provided as Alt Text is NOT an equivalent experience for a blind user.

Contrast for non-text chart elements

There is no contrast requirement for a non-text chart element when an accessible text alternative, such as a data table or a data label, has been provided. When an accessible text alternative has not been provided, a minimum contrast ratio of 3:1 is required between the color values of a non-text chart element and the background, and/or elements that are adjacent to it.

Returning to the example file, I'll open the "Browser Market Share" sheet. This is a pie chart we have reproduced from an example provided online for the WCAG Success Criteria 1.4.11: Non-text Contrast:

We have provided a link to this page in the Resource Links for this Section.

This chart fails 1.4.11, as explained on the page:

The pie chart has labels for each slice (so passes 1.4.1 Use of Color),
but in order to understand the proportions of the slices you must discern the edges of the slices (the graphical objects conveying essential information),
and the contrast between the slices is not 3:1 or greater.

Fortunately, Excel pie charts feature a border between shapes by default. Each shape in this example must have 3:1 contrast with its white border. Five of the shapes meet this requirement, but the yellow shape labeled "Safari" does not:

To address this issue, I'll change the shape's color to a darker yellow.

To change a chart shape's color:

    1. Click the Chart Area.

    2. Click the shape.

    3. Select "Format Data Point" from the menu.

    4. On the "Format Data Point" side panel, click the "Fill & Line" tab.

    5. Expand the "Fill" section.

    6. Click on the "Color" tool and select "More Colors" from the picker.

    7. On the "Color" dialog, enter the new values on the "Custom" tab.

    8. Click "OK".
